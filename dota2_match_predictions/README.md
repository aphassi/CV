# Предсказание исхода матчей Dota 2

Учебный проект по табличному машинному обучению и генерации признаков на данных матчей Dota 2.

Задача проекта — предсказать вероятность победы команды **Radiant** по информации о матче и выбранных героях. Основной акцент сделан на предобработке данных, feature engineering и подборе гиперпараметров модели.

## Что реализовано

- обработка даты матча и генерация признаков `day` и `dayofweek`;
- One-Hot Encoding региона и дня недели;
- обработка пропусков в среднем рейтинге игроков `avg_mmr`;
- признаки `mmr_missing` и `sqrt_mmr`;
- собственный `HeroesEncoder`, кодирующий выбранных героев:
  - `+1`, если герой выбран Radiant;
  - `-1`, если герой выбран Dire;
- объединение табличных и разреженных признаков;
- бинарная классификация с помощью `LogisticRegression`;
- подбор гиперпараметров через Optuna;
- оценка качества по коэффициенту Gini на основе ROC-AUC;
- формирование файла с предсказаниями для тестовой выборки.

## Метрика

В проекте используется коэффициент Gini:

```text
Gini = 2 * ROC-AUC - 1
```

В сохранённом запуске финального ноутбука лучший Gini на validation составил примерно **0.306**.

## Данные

Код ожидает следующие файлы:

```text
matches_df_train.csv
matches_df_test.csv
player_df.csv
Constants.Heroes.csv
```

Датасет в репозиторий не включён.

По умолчанию скрипт ищет данные в папке `data/`. Путь можно передать явно через `--data-dir`.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить обучение:

```bash
python -m src.train --data-dir data
```

По умолчанию выполняется 8 trials Optuna. Количество можно изменить:

```bash
python -m src.train --data-dir data --trials 25
```

После обучения создаётся файл:

```text
submission.csv
```
