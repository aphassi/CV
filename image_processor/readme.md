# Image Processor

Консольное приложение на **C++** для обработки изображений в формате **24-битного BMP без сжатия**.  
Проект реализован без использования сторонних библиотек для работы с изображениями.

Программа загружает BMP-файл, последовательно применяет указанные пользователем фильтры и сохраняет результат в новый файл.

## Возможности

- чтение и сохранение 24-битных BMP-изображений;
- последовательное применение нескольких фильтров;
- обработка параметров через командную строку;
- корректная обработка некорректных аргументов и неподдерживаемых файлов;
- работа с изображением на уровне отдельных пикселей.

Поддерживаются базовые фильтры:

- `-crop width height` — обрезка изображения;
- `-gs` — перевод в оттенки серого;
- `-neg` — негатив;
- `-sharp` — повышение резкости;
- `-edge threshold` — выделение границ;
- `-blur sigma` — гауссово размытие.

## Использование

Формат запуска:

./image_processor input.bmp output.bmp [filters...]

## Формат изображений

Приложение работает с BMP-файлами следующего формата:

-24 бита на пиксель
-без сжатия
-без таблицы цветов

## Архитектура

Проект разделён на компоненты для:

-представления изображения и цвета
-чтения и записи BMP
-реализации фильтров

Фильтры построены как отдельные компоненты, что позволяет расширять приложение новыми операциями обработки.
