# CV Projects

Репозиторий c проектами по машинному обучению, анализу данных и разработке.

## Проекты

### [Dota 2 Match Prediction](./dota2_match_predictions)
Модель бинарной классификации для предсказания исхода матчей Dota 2.  
Feature engineering, Logistic Regression, Optuna, Gini / ROC-AUC.

**Стек:** Python, pandas, scikit-learn, Optuna

### [MovieLens Recommender](./movielens_recommender)
Рекомендательная система на основе матричной факторизации.  
Реализация ALS, сравнение с Randomized SVD и Sparse SVD, оценка по Hit Rate.

**Стек:** Python, NumPy, SciPy, scikit-learn

### [Taxi Chats Analysis](./taxi-chats-analysis)
Модуль анализа сообщений из чатов таксистов: поиск точных и почти дублей,
эмбеддинги и семантический поиск.

**Стек:** Python, PostgreSQL, pgvector, Prefect, Superset

### [Image Processor](./image_processor)
Консольное приложение для обработки 24-битных BMP-изображений без использования
сторонних библиотек для работы с изображениями.

**Стек:** C++, STL, CMake
